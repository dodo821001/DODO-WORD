이번 버전은 가맹문의 폼을 실제 접수용으로 변경했습니다.

작동:
홈페이지 폼 → Google Apps Script → Google Sheet 저장 + 담당자 이메일 알림

필요한 최초 설정은 google-apps-script/설치방법.txt를 따라 진행하면 됩니다.
설정 완료 후에는 홈페이지에서 들어오는 문의가 자동으로 누적됩니다.

CMS 관리자(admin.html)에서 수정 가능:
- 상담 접수 Web App URL
- 접수 완료 문구
- 오류 문구
- 개인정보 동의 문구
- 개인정보 처리 안내
- 기존 가맹문의 텍스트 및 버튼 문구

중요:
Google 계정의 권한 승인과 웹 앱 배포는 계정 소유자가 한 번 직접 해야 합니다.
