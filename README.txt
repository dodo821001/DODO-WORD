DODO WORLD 고퀄리티 홈페이지 시안

- index.html : 도도 월드 인터랙티브 미니 약도 메인
- about.html : 도도란?
- cafe.html : 만화카페 도도 / 콘텐츠 / 먹거리
- stores.html : 매장소개
- franchise.html : 가맹문의
- assets/images : 실제 도도 매장 및 브랜드 이미지
- assets/style.css : 반응형 전체 디자인
- assets/app.js : 스크롤/등장 애니메이션

확인 방법
1. 압축을 풀고 index.html을 열어주세요.
2. 또는 GitHub 저장소 루트에 그대로 업로드 후 Pages를 켜면 됩니다.

참고
- 가맹문의 폼은 현재 디자인 시안이며 실제 접수 기능은 아직 연결하지 않았습니다.
- 메뉴의 '전체 메뉴 보기'는 강남 메뉴판 주소에 연결해 두었습니다.
- 다음 단계에서 매장별 상세 주소/영업시간, 네이버 지도, 실제 문의 접수(구글시트/메일) 연결이 가능합니다.
